# 問題データ

問題は「学年 × 教科」で分離します。

例：
- `grade1/japanese.js`
- `grade1/math.js`
- `grade1/life.js`
- `grade2/life.js`
- `grade3/science.js`
- `grade6/social.js`

各問題は次の形を基本にします。

```js
{
  id: 'g1-life-001',
  grade: 1,
  subject: '生活',
  type: 'choice',
  question: '学校で そだてるものとして ただしいものは？',
  choices: ['あさがお', 'さかなのえさだけ', 'くるま'],
  answer: 'あさがお',
  hint: 'はなを さかせる しょくぶつだよ。'
}
```

算数の数値問題などは `type` を `numeric` にして `answer` を数値にできます。

## 分野タグ（cat）

各問題には `cat`（分野）があります。「バトルのじゅんび」の「③ 分野をえらぼう」で、出題する分野をしぼれます（「おまかせ」は全分野から出題）。

- 算数：計算／図形／単位・量／その他
- 国語：漢字／ことば／よみとり／その他
- 理科・社会：学年ごとの単元名（例：4年理科「天気と水の変化」）
- 生活：せいかつと安全／がっこうとまち／自然と季節／生き物と植物／その他
- 英語：あいさつと自己紹介／数・色・曜日／食べ物と動物／好きなこと・できること／その他

分野は3問以上あるものだけがボタンに出ます（少ない分野の問題は「おまかせ」に含まれます）。

3〜6年生の問題は `all-grades.js` にまとめて入っています。`js/app.js` の `loadQuestions` が、学年別ファイルが無いときに `all-grades.js` を読み込んで補います。
