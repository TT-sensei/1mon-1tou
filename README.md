# 教科モンスターバトル｜1問1とう

小学生向けの一問一答バトル教材です。GitHub Pagesで動作し、ビルド工程や独自サーバーは不要です。

## 新しい試作版：ナビアン・クエスト

[ナビアン・クエストを開く](https://tt-sensei.github.io/1mon-1tou/quest.html)

既存版を残したまま、ゲームの中心をゼロから組み直した試作版です。ナビアンをカードにして問題に挑み、カードを育て、間違えた問題を特訓し、図鑑から好きな仲間を選んで集めます。試作版は既存版と別の保存領域を使います。

設計のねらい、ゲームの流れ、現在の問題データの範囲は REDESIGN.md にまとめています。

## 設計方針

この教材は edu-kit の役割分担を基準に、教材固有の処理と共通基盤を分離しています。

- edu-components：問題プール、正誤判定、得点、保存
- edu-effects：基本UI、学習UI、正誤表示、動き
- 1mon-1tou：教科、問題、モンスター、カード、バトルルール

## 構成

- index.html：既存版の画面の骨格
- quest.html：ナビアン・クエストの試作版
- css/app.css、css/battle.css：既存版の画面
- css/quest.css：試作版の画面
- js/app.js、js/battle.js：既存版の画面遷移・カード・バトル処理
- js/quest.js：試作版のクエスト、特訓、育成、カード図鑑と保存
- js/card-render.js：カードの画像・枠・背景の描画
- data/subjects.js：教科定義
- data/monsters.js：ナビアンの定義
- data/cards.js：既存版のカード定義
- data/questions：学年・教科ごとの問題
- assets：カード背景・枠・裏面などの素材

## 既存版のバトル

学年と教科を選び、1回のバトルで3体のモンスターと戦います。正解するとカードが攻撃します。モンスターの得意教科と選んだ教科が一致すると、追加ダメージを与えます。不正解はゲームオーバーにせず、ヒントを表示して同じ問題に再挑戦できます。

正解で10カードP、3体撃破で追加20カードP。間違えた問題は教材固有の保存領域に記録します。

## 問題データ

問題は「学年 × 教科」で分離します。ファイル名は grade1/japanese.js、grade1/math.js、grade1/life.js、grade2/life.js などの形式です。各問題は id、grade、subject、type、question、choices、answer、hint などの値を持つオブジェクトとして定義します。算数の数値問題などは、出題形式に応じた answer を用意します。

現在同梱されている問題データは、小学1・2年生の国語、算数、生活、英語です。3〜6年生や理科・社会の問題を追加したときは、実際の問題データに合わせて出題範囲を広げます。

## カード

既存版ではモンスター、得意教科、エフェクト、背景を組み合わせてカードを生成します。カードとモンスターの定義はデータファイルに分離されているため、後からレベル、属性、スキル、レアリティ、進化などを追加できます。

試作版では、カードの重複やランダムなカードパックより、学習で得たカードPを使い、図鑑から欲しいナビアンを選んで仲間にすることを重視します。

## 保存

既存版は edu-components の StorageManager を使用し、namespace は 1mon-1tou です。試作版は保存領域を 1mon-1tou-quest に分け、既存版のカードPやチーム、間違えた問題を変更しません。進行状況はブラウザ内に保存されます。

## 開発ルール

新しい機能を追加するときは、まず edu-kit の設計原則と共通基盤を確認します。教材側に既存の共通部品と同じ Manager や判定処理を作らないことを基本とします。

バトルの学習判定は edu-components、見た目と演出は edu-effects、教材固有のモンスター・カード・問題・ゲームルールは 1mon-1tou に置きます。外部API、独自サーバー、ビルド工程、追加費用の発生するサービスは導入しません。
