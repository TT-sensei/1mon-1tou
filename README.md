# 教科モンスターバトル｜1問1とう

小学生向けの一問一答バトル教材です。GitHub Pagesで動作し、独自サーバーやビルド工程は不要です。

## 新しい試作版：ナビアン・クエスト

[ナビアン・クエストを開く](https://tt-sensei.github.io/1mon-1tou/quest.html)

既存版の画面や保存データを残し、新しいゲーム設計を別ルートで試せるようにしています。ナビアンをカードにして、問題を解きながらカードを育て、間違えた問題を特訓し、図鑑から好きな仲間を集めてチームを編成します。ランダムなカードパックをやめ、学習とカード収集のつながりをわかりやすくしました。

再設計の考え方、ゲームの流れ、現状の問題データの範囲は REDESIGN.md を参照してください。

## 既存版

トップページは従来の教科モンスターバトルをそのまま維持しています。学年と教科を選び、1回のバトルで3体のモンスターと戦います。カード、カードP、チーム、間違えた問題は既存版の保存領域に記録されます。

## ファイル構成

- index.html：既存版の入口
- quest.html：ナビアン・クエストの試作版
- css/app.css、css/battle.css：既存版の画面
- css/quest.css：試作版の画面
- js/app.js、js/battle.js：既存版の処理
- js/quest.js：試作版のバトル・特訓・育成・保存
- js/card-render.js：カード画像の描画
- data/subjects.js：教科定義
- data/monsters.js：ナビアンの定義
- data/questions：学年と教科ごとの問題データ
- assets：既存のカード素材

## 技術方針

静的なHTML・CSS・JavaScriptを基本にし、独自APIやサーバーは追加しません。ユーザーの進行状況はブラウザ内に保存します。既存版と試作版では保存領域を分けています。

## 問題データ

同梱されている問題データは現時点で小学1・2年生の国語、算数、生活、英語です。ほかの学年・教科は問題データの追加にあわせて対応します。
