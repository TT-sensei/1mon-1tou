# 教科モンスターバトル｜1問1とう

GitHub Pages でそのまま動く、**1問とくと攻撃できる**小学生向けの一問一答ゲームです。外部ライブラリやビルド工程は不要で、`index.html` を開くだけで遊べます。

## 遊び方

1. **バトルする**から学年と教科を選びます。`おまかせ` は、その学年で実際に問題データがある教科から選びます。
2. 問題に正解すると、画面中央に現れる**敵モンスター**へ攻撃します。敵の得意教科なら **2ダメージ**、それ以外でも **1ダメージ** です。左側には自分のチームカードを表示するため、攻撃対象と区別できます。
3. 間違えてもゲームオーバーにはなりません。ヒントを見て再挑戦でき、問題は「まちがえた問題」に保存されます。
4. 正解ごとに10カードP、3体を倒してクリアすると20カードPを獲得します。
5. 100カードPでカードパックを引けます。同じカードの場合は50Pが戻ります。

## 対応学年・教科

教科の学年対応は `data/subjects.js` で管理しています。画面には、対応学年であり、かつ実際の問題データが存在する教科だけを表示します。現在同梱している問題は以下です。

- 1年生：国語、算数、生活
- 2年生：国語、算数、生活
- 3〜6年生：問題データ準備中（選んでもエラーにはなりません）

## カードとモンスター

- 初回は3枚のカードで始まり、カード画面で最大3枚のチームを編成できます。
- モンスターのランクはザコ（HP 1）、進化系（HP 2）、ボス（HP 3）です。問題の難しさとモンスターHPは独立しています。
- カードはランクに応じた**背景画像・フレーム画像・モンスター画像**の3レイヤーを重ねるデータ駆動の構成です。カード比率は `3:4` で、スマートフォンでも崩れません。
- プレイヤーカードと敵モンスターには、それぞれローカルのSVGモンスター素材を使用するため、外部画像の読み込みに失敗してカード裏面だけが表示されることはありません。

## データ構成

- `data/subjects.js`：教科名、ID、対象学年、アイコン。
- `data/questions/grade*/`：学年・教科ごとの4択問題。各問題は `id`、`question`、`choices`、`answer`、`hint` などを持ちます。
- `index.html`：画面、モンスター定義、カード描画、バトル、復習、設定を含む単体アプリケーションです。

## 画像構成

- `assets/cards/backs/card-back.jpeg`：共通のカード裏面。
- `assets/cards/backgrounds/zako/`：ザコ・進化系カードの背景。
- `assets/cards/backgrounds/boss/`：ボスカードの背景。
- `assets/cards/frames/`：`zako.png`、`zako-evolved.png`、`boss.png` のランク別フレーム。
- `assets/monsters/`：プレイヤーカードと敵バトル用のローカルSVGモンスター素材。

すべてのモンスター素材はリポジトリ内に含まれるため、オフラインでもカードと敵モンスターを表示できます。

## 保存データ

ブラウザの `localStorage` に以下を保存します。壊れたJSONは安全に初期値へ戻します。

- カードP
- 所持カードとチーム
- 間違えた問題（問題ID、問題文、学年、教科、間違い回数、最終日時）
- 設定（音、演出）

「せってい」から確認ダイアログ付きで保存データをリセットできます。

## GitHub Pages での利用

このリポジトリの公開元を GitHub Pages に設定し、ブランチのルートを公開してください。依存関係やサーバー設定は不要です。ローカル確認はリポジトリ直下で `python3 -m http.server 8000` を実行し、`http://localhost:8000/` を開きます。
